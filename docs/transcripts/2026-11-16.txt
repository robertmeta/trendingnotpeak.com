Give browser agents more useful work per call

First up, Turbo-Browser-MCP changes the size of a browser agent's next step. This newly introduced server builds on Playwright, with tools that fill a form in one call, batch browser steps, and return changes to the page instead of another complete snapshot. It also enables a submit guard by default. If you're building an assistant that works through repetitive forms, those are concrete design choices to investigate. You could use Turbo-Browser-MCP to batch browser form filling while keeping the eventual submission a separate point to inspect. The project aims to reduce agent turns and tokens; there isn't an independently established saving to promise here. The MIT-licensed implementation includes eleven tools and benchmark material. A useful first comparison would run the same local test form through your current browser tools and this server. Count calls and inspect the completed fields together. Fewer exchanges become valuable when the agent still understands which page changed and which action it is about to take.

One revealing experiment would check whether a policy's improvement survives when the evaluator changes, rather than only judging whether the generated video looks convincing.

Those filters can inject JavaScript, so an interface meant to remove page elements became a path into other websites' contexts. The report also identifies a related, less problematic issue in uBlock Origin Lite. Walk through the report with that trust boundary in mind, then examine whether your own extension keeps page-controlled messages separate from operations that grant lasting privileges.

Build Rust date APIs around a new stability commitment

Back from the break, Jiff has reached one point zero. Pronounce it with a soft G, like gem. Andrew Gallant's Rust datetime library puts time zones at the center of its API and automatically handles many common daylight-saving problems. The fresh development is a stability commitment: Gallant intends to maintain the one point zero API indefinitely unless a significant defect requires a change. That matters if your own library exposes datetime values in its public interface, where an incompatible dependency update can ripple into everybody else's code. Jiff already appears in projects including Cargo, uv and Jujutsu, so this is an established library entering a new compatibility phase. Rust developers can use Jiff to handle time zones and explore the release through complete, runnable examples in the announcement. Record one Mac application's audio stream

Turning to audio, Umbrella is a newly introduced Mac app for recording an individual application's sound into MP3 or AAC files. The product page describes separating the chosen stream from other applications, including background notifications, with downloads for Apple Silicon and Intel Macs. It also says all processing stays on the machine. Developers making application demos or collecting audio from their own test software could use Umbrella to capture per-app audio without mixing every sound the desktop happens to produce. The practical comparison is straightforward: play a known clip in one app, trigger an unrelated notification, and listen to the recording. The site's zero-latency and negligible-CPU descriptions are product claims, without independent measurements here. Timed recording and automatic stop controls are marked coming soon. For now, the concrete possibility is a manually controlled recording of one application's output, with selectable export bitrates. That's a pleasantly small component to explore when the rest of your workflow already does what you need.
