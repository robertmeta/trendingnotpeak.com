Put a reproducible database demo inside a link

First up, Datasette Lite has a complete rewrite that makes a browser tab a surprisingly capable database demonstration. Simon Willison's Python application runs through WebAssembly and Pyodide, with service workers helping it behave like the server version. A carefully constructed link can select a Datasette release or development commit, load a database, choose among more than a hundred SQLite versions, and install plugins. That gives library maintainers a lovely way to share database demos or reproduce a bug without asking somebody to launch a server. The announcement demonstrates a mapping plugin displaying country boundaries from a SQLite database. Remote data files need open cross-origin access headers, so an arbitrary download link won't always work. Datasette Lite makes the configuration part of what you share. Imagine sending a teammate the exact database, plugin and application version behind a confusing result, with the experiment ready to open in their browser.

Give latent reasoning a measure of progress

Turning inside the model, Energy-Based Reasoners give a repeated reasoning loop something to follow. These models refine hidden internal states rather than spelling out every intermediate step. The researchers train an energy function that scores those states. Its gradient guides the next refinement, and the score provides a signal for when to stop. Their exploration-based training also visits additional candidate states to shape that landscape. Across four algorithmic reasoning benchmarks, the authors report matching or beating earlier recurrent models. On Sudoku-Extreme, they report ninety-nine point nine percent accuracy with three hundred forty-five times less inference compute than the next-best model, at comparable training compute. That's a specific research comparison, rather than a promised acceleration for chat assistants. Researchers studying adaptive computation could investigate whether a learned progress signal spends fewer iterations on easy problems. Compare correct answers, stopping behavior and compute together; a confident stopping rule needs to recognize when the puzzle is actually finished.

Find Python names that nobody uses

Closer to everyday maintenance, Unref is a newly introduced Python dead-code finder written in Rust and built on Ruff's parser. Its useful detail is how it matches names: a used function called parse in one module shouldn't hide an unused parse somewhere else. The project also includes rules for frameworks such as pytest, Pydantic and SQLAlchemy, where a name can have a job that ordinary references don't reveal. Python maintainers could use Unref to find unused Python code before a cleanup or refactor. The author reports checking roughly twenty-three hundred CPython files in under a second, about twenty times faster than Vulture in that benchmark. Speed makes repeated inspection inviting, although a report still needs review before deletion. Start with a module you know well, examine the proposed unused names, and check whether framework callbacks remain recognized. Unref gives that cleanup conversation a concrete set of candidates.

Revisit a driving scene with a different LiDAR

Out on the simulated road, NVIDIA Research's LidarVerse generates the laser scans a vehicle uses to describe its surroundings in three dimensions. The same model changes jobs according to the scene evidence it receives. Maps can guide a new scene, an observed sequence can lead into a forecast, and sparse recorded sweeps can anchor a reconstruction viewed from another position. A shared tokenizer supports thirty-two, sixty-four and one hundred twenty-eight beam sensors. The team reports that its distilled causal checkpoint runs at ten frames per second on one H-one-hundred GPU. For perception researchers, the opening is testing how a scene might appear under a different viewpoint or scanning configuration. That could help investigate a sensor change before collecting an entirely new dataset. Generated scans still need comparison with recorded geometry. Pick a scene with known measurements and inspect whether important objects remain consistent as you change the virtual sensor.

Share a tracking model across live camera feeds

Back with ordinary cameras, tamserve tackles the machinery around tracking objects across video frames. Its introduction explains that SAM Two and the smaller EdgeTAM were written around one recorded video at a time. Tamserve supplies a serving engine for live, multiple-camera tracking, with one model copy per GPU serving the cameras. The project describes operation on one GPU or several and claims about four times less GPU memory than the original code, with identical masks. Those comparisons come from the project. Developers building a workshop camera tool or a live visual interface could investigate whether sharing the model makes several feeds practical on existing hardware. Begin with two repeatable video streams and a clearly identifiable object in each. Measure memory alongside frame delay and tracking quality. The useful result would be a service that keeps up with both streams without quietly sacrificing the object you wanted to follow.

Inspect the evidence behind an autonomous security test

At the application boundary, Reflection has introduced Laser, an autonomous penetration-testing harness for its terminal agent, Mirror. The interesting design is the separation between acting and reviewing. An executor tests the scoped target and records observations in a shared evidence ledger. A separate supervisor reviews that evidence and guides the next turn, including when an approach stalls. Reflection says findings include attack graphs and captured evidence, giving security teams a way to inspect how a conclusion was reached. Laser is a research preview available exclusively to commercial partners accepted into the new Trusted Access Program. Security teams evaluating agent-assisted testing could examine whether that ledger makes findings easier to reproduce and turn into repairs. For a trial on an authorized test application, follow one finding backward from the report to the recorded observation. The practical question is whether another engineer can establish the same failure from that trail.

Automate proofs for a particular family of compilers

Over at the proof bench, Adam Chlipala describes new research using e-graphs to automate compiler verification. E-graphs efficiently represent many equivalent expressions, which makes them useful for exploring rewrites. This work applies that machinery to compiler definitions for languages the tool hasn't previously seen, without additional annotations written specifically to guide the proof. There's an important boundary around the result: these are research compilers for functional languages, with intermediate stages checked by sound type systems. This isn't an automatic correctness check for GCC or Clang. Programming-language researchers could investigate whether a compiler structured around those typed stages becomes easier to verify as it evolves. The paper is headed to POPL twenty twenty-seven; Chlipala points readers to Dustin Jamner's dissertation while the final paper is still pending. Follow the article's small function example through its compilation stages and see what each representation makes possible to prove.

Blend a bird from numbers and colors

And finally, Birds drawn by code gives procedural graphics a very approachable subject. Nicolas Jonason's interactive generator represents each bird with forty-six numbers and seventeen colors. Drag across the map, and it blends the nearby birds. Open the panel underneath, and you can read the code, which Jonason says an agent wrote for him. Creative coders and people learning generative art get a small, inspectable example of turning a visual family into adjustable parameters. You could follow how a shape changes as you move, then find the corresponding operation in the implementation. The demo doesn't establish a general method for generating animals, and it doesn't need to. There's plenty to explore in one numerical flock. Move between two birds and look for the moment the blend starts to feel like a new character.
